# Akdas Amjad | Premium Developer Portfolio

A production-ready, high-performance personal portfolio built with Next.js 14, TypeScript, and Tailwind CSS.

## 🚀 Tech Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Deployment:** Vercel
